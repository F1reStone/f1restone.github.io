## 愿景

    </div>
    <div class="lg:col-span-7 lg:col-start-6">
      随着虚幻 5 引入 **Nanite、Lumen、Blueprint 以及 Chaos** 等新技术，画面表现力和易用性迎来了显著提升，但也带来了更高的性能开销与复杂度。在部分项目场景中，这种设计并不是最优解。燧光分支正是在这一背景下诞生，其核心目标是在旧版虚幻中通过对引擎进行现代化改进、依赖升级、整合高性能技术，例如 NVIDIA RTXGI、Angelscript 等，实现一个**更可控、开销更低、更接近传统技术栈**的体系，以替代 Epic 技术栈。
    </div>

  </div>
</section>

## 底层

    </div>
    <div class="lg:col-span-7 lg:col-start-1 lg:row-start-1">
      - SparkForge-5.8Base 分支底层基于 **UnrealEngine-Angelscript** 分支，引擎版本 **5.8.3**。未来计划 merge 更多来自 5.0 - 5.8 版本的外围代码和插件更新。
      - SparkForge-5.3Base 分支底层基于 **NvRTX-5.3** 分支，引擎版本 **5.3.2**。未来计划 merge 更多来自 5.0 - 5.8 版本的外围代码和插件更新。
      - SparkForge-5.0Base 分支底层基于 **NvRTX-5.0** 分支，引擎版本 **5.0.3**。未来计划 merge 更多来自 5.0 - 5.8 版本的外围代码和插件更新。

## 核心功能

    </div>
    <div class="lg:col-span-7 lg:col-start-6">
      - 基于 **RTXGI / RTXDI / SSR / 传统 AO** 的光照
      - 支持 **NVIDIA DLSS 4**[^*1]、**AMD FSR 4 “Redstone”**[^*2]、**Intel X<sup>e</sup>SS 3**[^*3]
      - **Angelscript** 支持[^*4]
      - 更高的性能可控性与调优空间
      - 针对旧版虚幻的 **Visual Studio 2026**[^*5]、JetBrains Rider[^*6] 编译适配
      - **最新 Windows SDK** 适配[^*7]
      - **最新 Microsoft Visual C++** 适配[^*8]
    </div>

  </div>
</section>
